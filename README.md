Entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun.

## The line

> House rules, section 4: any sock left on the floor for over 24 hours is legally dust.

- Prompt answered: the excuse a robot vacuum gives after eating a sock.
- Length: 85 characters (1–200 required), single line, no trailing newline.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```
